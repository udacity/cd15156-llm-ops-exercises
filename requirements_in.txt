# requirements_in.txt — direct dependencies for the ONE Vocareum Workspace image
# that serves BOTH the 12 Course 2 (LLM Ops) implementation-module exercises AND
# the capstone project. A single image, one manifest, both workloads.
#
# Scope:
#   Union of the `[project].dependencies` and `[dependency-groups].dev`
#   entries from each exercise's solution/pyproject.toml under
#   exercises/<NN>-<topic>/solution/, AND the capstone's
#   project/pyproject.toml (runtime deps + dev group). Solutions are a
#   superset of starters (the starter for m18 omits `tenacity`; learners
#   add it while doing the exercise — so the image must ship it).
#
#   The capstone adds ZERO packages: every project/pyproject.toml dependency
#   is already present here with a compatible pin (the capstone is a strict
#   subset of the exercise closure by package name). The only version-range
#   difference was `openai` — the capstone allowed `<3`, this image pins `<2`
#   (the tested 1.x path, openai==1.109.1); `<2` satisfies both, and the
#   capstone pyproject was tightened to match. Verified: this pinned image
#   passes the full 231-test capstone suite (see requirements.txt header).
#
# Target:
#   Vocareum Udacity Workspace, Python 3.11 (pyproject pins 3.11-3.13).
#   OpenAI access is provided via Vocareum env vars (`OPENAI_API_KEY`,
#   `OPENAI_BASE_URL=https://openai.vocareum.com/v1`); no code changes
#   needed — clients already read those.
#
# Regenerate the pinned `requirements.txt` from this file with:
#   uv pip compile requirements_in.txt -o requirements.txt
#
# Notes:
# - `en-core-web-sm` is a URL-pinned spaCy English NER wheel (binary
#   install, no compile). Presidio (which llm-guard's Anonymize wraps)
#   needs it as its tokenizer / sentence-segmenter backbone.
# - `arize-phoenix` is pinned <14 because Phoenix 14+ conflicts with
#   `llm-guard` via `cryptography` (Phoenix wants >=45; llm-guard wants
#   <44.1). `arize-phoenix-evals` is pinned <3 because Phoenix 13.21
#   imports `phoenix.evals.models` which was removed in evals 3.x.
# - `pytz` is declared explicitly because `arize-phoenix` imports it
#   in `phoenix/datetime_utils.py` without declaring it.
# - The image should also pre-cache the HuggingFace models warmed by
#   `make install-guardrails-models` per the 2026-05-03 workspace-image
#   audit (DeBERTa prompt-injection, BERT-NER, MoritzLaurer NLI,
#   MiniLM, en_core_web_sm) — that's separate from this pip install.
